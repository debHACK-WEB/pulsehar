# Contributing to PulseHAR

Thank you for your interest in **PulseHAR**.

## Authorized Use Only
All testing, sample data, and contributions must follow ethical and legal authorization rules. Never use this tool against targets without explicit permission.

## How to Contribute
1. Fork the repository and create a new branch from `main`.
2. Keep changes focused and well-tested (`pytest`).
3. Document any new detection rule under `rules/` (what it detects, why it matters, and expected false positives).
4. Submit a clear Pull Request describing the change and how it was tested.
